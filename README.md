# Project Purpose
This project simulates a Python script as a Calculator using Object‑Oriented Programming (OOP) principles. It demonstrates how to design a class with methods for basic arithmetic operations and extend functionality with advanced mathematical features. The project also integrates error handling and answer storage to improve usability.

# Project Preview

# Features
Basic Operations: Addition, subtraction, multiplication, division (with zero‑division protection).

Extended Functions: Power, square root, cube root, nth root.

Constant Access: Returns the mathematical constant π using the math module.

Answer Storage: Every result is saved in a list until the program exits, allowing users to review past calculations.

Error Handling: Gracefully manages invalid input, division by zero, overflow, and unexpected errors.

# Methods
Tool: Python programming language with the built‑in math module.

Approach: Encapsulation of operations in a Calculator class, interactive menu loop for user input, and structured exception handling.

# Results
The calculator runs interactively, allowing users to perform multiple operations in sequence. Results are stored and displayed at exit, ensuring users can track their calculation history. The project highlights practical application of OOP, exception handling, and user interaction in Python.
